# dev4 开发候选（未发布）

本分支增加累计搜索与手动 CSV 导出，并修复详细窗口的两项显示问题。`0.2.1.dev4` 用于区分新候选与已发布 dev3；没有创建新 Release，README 的公开下载仍固定为 dev3。

## 使用与数据边界

打开“详细信息 → 本次监控累计”，按应用名称、路径或账户标识搜索。搜索不区分大小写，只影响本页显示，不删除账户，不影响实时页筛选、采集或累计。清空搜索可恢复全部有已确认流量的账户，包括已退出账户。

“导出 CSV…”保存点击时当前搜索结果，顺序与表格一致。保存对话框打开后发生的新采样或筛选变化不会混入该文件；取消、保存失败和导出成功均不清零累计。没有搜索结果时按钮禁用。文件使用 UTF-8 BOM，可保留中文名称；数字列是十进制原始字节数。电子表格软件可能自行舍入超长数字，需要精确处理时按文本导入字节列。

默认字段：`application`、`download_bytes`、`upload_bytes`、`process_count`、`process_state`、`source_status`、`exported_at_utc`。进程数量未知时为空，不用零代替；采集不可用时仍可导出此前已确认累计，并保留来源状态。`exported_at_utc` 是点击导出时刻，不是首次采集时刻或每个账户的最后活动时间。导出不构成长期流量数据库，不含速率积分、协议开销补偿或新归属推断。

路径及账户标识默认省略，只有勾选“导出包含路径和账户标识”才加入 `executable`、`account_key`。即使不勾选，应用名称也可能包含私人信息，分享前应检查内容。可能被电子表格当作公式的应用文本会加单引号前缀；原始数值不改变。文件只写入用户选择的位置，不上传、不自动定时导出。写入使用 Qt QSaveFile 的临时文件提交机制，禁止直接覆盖回退，避免写入失败损坏原文件。
