# Net Monitor 0.2.1.dev5 发布记录

Windows 11 x64 **Pre-release**，未签名，不是稳定版。

## 本版变化

- 全新应用图标：蓝色上行与薄荷绿下行箭头组成 N 形轮廓，统一用于 EXE、默认窗口和托盘。
- ICO 包含 16、20、24、32、40、48、64、128、256 像素，适配不同显示尺寸；构建逐帧核对 EXE 内嵌图标、运行资源和源图标一致。
- 保留 dev4 的本次累计搜索、CSV 导出及已有采集行为。本版未修改采集、PID 身份归属、累计或按应用图标逻辑。

## 已验证范围

图标源码完整回归 365 passed、1 skipped，Windows x64／ARM64 和 x64 打包 CI 通过。最终公开包通过 ZIP CRC、323 项清单及 208 项构建输入核对；Windows 原生 API 能读取新 EXE 图标，9 个内嵌尺寸与运行时 ICO 一致。

dev5 是新的包，未重复进行实际提权采集、两小时观察或原生 CSV 核对；dev4 对应哈希的历史结果仍只属于 dev4，不视为本版通过。此发布不代表稳定版验收完成。按用户决定跳过虚拟机验证，Windows 部署部分等待 GitHub 直接下载后的真实反馈；真实双屏／混合缩放、完整交互与性能覆盖及代码签名仍未完成。
