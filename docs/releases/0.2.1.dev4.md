## 使用与验收边界

完整解压 ZIP 后运行 `NetMonitor/NetMonitor.exe`，保留 `_internal` 等全部内容，无需另装 Python。按应用采集需要使用程序内管理员重启入口，并由用户处理 UAC；Compact“窗口 → 退出”用于真正结束程序。

累计仅涵盖本次监控已确认的数据，不跨重启保存。PID 身份不确定区间采用保守归属，可能少计未知区间或退出尾部。默认 CSV 不含路径／账户标识也不代表完全匿名，分享前应检查应用名称等内容。校验和不是数字签名。

独立 Windows 11 x64 虚拟机已安装并观察到程序启动，用户反馈良好；后续来宾核验按用户要求跳过，干净机器完整验收仍未验证。当前物理主机只有单屏 150%，真实双屏、混合缩放和断开屏幕仍待对应环境。Micro／Card 全部交互、托盘隐藏恢复、固定关注、原生取消和性能三场景也未由本轮观察完整覆盖。代码签名单独安排，详见[稳定版验收](../stable-readiness.md)。
