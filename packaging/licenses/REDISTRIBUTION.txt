To install an interface-compatible modified library:
1. Exit Net Monitor and back up the whole extracted application directory.
2. Build matching sources for Windows x64, Python 3.14 ABI and Qt/PySide 6.11.2
   compatible interfaces using upstream Windows MSVC/CMake/Ninja instructions.
3. Replace appropriate files in _internal/PySide6 and _internal/shiboken6:
   Qt6*.dll, pyside6.abi3.dll/shiboken6.abi3.dll, *.pyd, plugins and Python
   wrappers. LGPL wrappers are external .py files, not exclusively embedded
   in the EXE. Keep compatible plugin layout/dependencies. Microsoft runtime
   files retain their separate terms and must remain unmodified.
4. Double-click NetMonitor.exe. No product signature or manifest enforcement
   blocks modified libraries. Keep modified files separate from the official
   ZIP; your modified directory will naturally differ from published hashes.

No key, activation, service or device lock is needed for compatible modified
libraries. Incompatible ABIs may fail to load; that does not alter LGPL rights.
Packaging checks external wrappers; not every possible modified Qt build was
exercised. Application rebuild inputs are at the commit in BUILD-INFO.json;
this document does not assign a license to the application's own source.
